# FirstGame1

**Unreal Engine 5.8.1 独立交互游戏 Demo / AIGC Project**

## 项目简介

独立完成的第三人称环境解谜 Demo，围绕“沉睡花园的复苏”设计教学、水、光、植物四阶段体验。

个人负责：

- 产品与体验定义
- 游戏流程设计
- 关卡与视觉方向
- Blueprint 交互
- AIGC 工作流与 AI 辅助开发
- 角色与资产接入
- 测试与效果验收
- Windows Build 与项目案例整理

使用工具：Unreal Engine、Blender、ChatGPT、Codex、Tripo、AccuRig、Seedance。

## Windows Demo

- 平台：Windows 64-bit
- 版本：Development 作品体验版
- 运行：完整解压 ZIP 后，双击根目录中的 **FirstGame1.exe**
- 操作：WASD 移动，Space 跳跃，E 交互

请保持解压后的文件夹结构完整，不要单独移动 **FirstGame1.exe**。
