## 项目体验

- **教学阶段**：激活音灵，理解世界恢复规则
- **水机关**：操作水压阀门，逐段恢复河流
- **光机关**：调整三面镜子，完成光束传导
- **植物机关**：搬运生命石，唤醒植物音灵并恢复花园

## 个人负责

- 产品目标、核心体验与完整流程定义
- 关卡结构、交互规则和视觉方向设计
- Unreal Blueprint 玩法实现与状态管理
- 角色、动画、环境资产和 AIGC 内容接入
- 问题诊断、PIE 验收、Windows Build 与案例整理

## AI / AIGC 工作流

- **ChatGPT / Codex**：需求拆解、实现方案、Blueprint 调试、测试标准与迭代复盘
- **Tripo / AccuRig / Blender**：角色生成、骨骼处理、模型检查与 UE 接入
- **Seedance**：项目演示内容的生成与镜头方案探索
- **Unreal Engine**：交互系统、关卡整合、视觉状态和最终可玩版本实现

## 技术与工具

Unreal Engine 5.8.1 · Blueprint · Blender · ChatGPT · Codex · Tripo · AccuRig · Seedance

## Windows Demo 操作

Windows 64-bit；完整解压后运行 **FirstGame1.exe**。

- **WASD**：移动
- **Space**：跳跃
- **E**：交互

> 可玩包发布后，请保持解压后的文件夹结构完整，不要单独移动 EXE。
